Arena Archive — Architecture & Implementation Plan

A private macOS desktop application for archiving and analyzing your own arena.ai conversations, with full local LLM operability via a dedicated MCP server.

Private use only Apple Silicon · macOS 14+ Dedicated browser app Multi-account isolation

1. Context & Scope

This plan designs a private macOS productivity and developer-research application for the model-comparison platform at arena.ai, including Arena Code and other conversation surfaces. The app records accurate local transcripts of your own conversations while you use Arena normally, supporting offline browsing, search, and local research into observed model behavior.

Fixed requirements:

  • Permanently private, single-user app — no distribution, App Store, hosted backend, or telemetry
  • Multiple Arena accounts signed in and usable simultaneously with full isolation
  • Apple Silicon only (M3 Pro, 18GB RAM, macOS 27+)
  • Local MCP server as primary interface — every GUI capability available to LLMs
  • Dedicated browser application — not an extension, debugger extension, or extension+companion

The existing Manifest V3 browser extension (musterm4nn-alt/arena-exporter) serves as a rejected baseline due to documented limitations: incomplete capture, missed conversation parts, dependence on page/runtime interception, and awkward download handling. The new architecture must provide materially deeper browser/session/network control.

3.3 Key Architecture Decisions

D1: Dedicated Browser Application (Not Extension)

DECISION Build a standalone Electron application that embeds Chromium directly.

Rationale: Extensions are constrained by browser security boundaries (MV3 service workers, limited network access, download restrictions). A dedicated application owns the browser process, enabling:

  • Complete network traffic observation via session.defaultSession.webRequest
  • Direct download handling without extension bridge
  • Process-level lifecycle management and debugging
  • Custom protocol handlers for internal resources

D2: Multi-Account Session Isolation

DECISION Use Electron's session.fromPartition('persist:arena-{account-id}') for each Arena account.

D3: Local MCP Server

DECISION Implement a local MCP server using the official TypeScript SDK.

Rationale: MCP provides a standardized, discoverable interface for LLM clients. Every application capability becomes a tool/resource with explicit contracts.

D4: SQLite with Encryption

DECISION Use SQLite with SQLCipher encryption for the primary database.

Rationale: Proven reliability, full-text search via FTS5, and strong encryption. Key stored in macOS Keychain.

Stream Reconstruction

For streaming responses (SSE, chunked HTTP), the capture pipeline reconstructs the full response from chunks:

class StreamReconstructor {
private buffers: Map<string, Chunk[]> = new Map();

addChunk(requestId: string, chunk: Chunk) {
const chunks = this.buffers.get(requestId) || [];
chunks.push(chunk);
this.buffers.set(requestId, chunks);
}

finalizeStream(requestId: string): CompleteResponse {
const chunks = this.buffers.get(requestId);
if (!chunks) throw new Error('No chunks found');

// Reconstruct based on content type
if (this.isSSE(chunks)) {
return this.reconstructSSE(chunks);
} else if (this.isChunkedHTTP(chunks)) {
return this.reconstructHTTP(chunks);
}

// Mark as unknown transport
return { type: 'unknown', chunks };
}
}

6.3 Sanitization Rules

Sensitive Data Exclusion List 
const SENSITIVE_PATTERNS = [
/authorization:\s*bearer\s+[a-z0-9\-._~+/]+=*/i,
/cookie:\s*[a-z0-9\-._~+/]+=*/i,
/x-csrf-token:\s*[a-z0-9\-._~+/]+=*/i,
/api[_-]?key[=:]\s*[a-z0-9\-._~+/]+=*/i,
/password[=:]\s*\S+/i,
/token[=:]\s*[a-z0-9\-._~+/]+=*/i,
// URLs with signed parameters
/[?&](sig|signature|token|key)=[^&\s]+/gi,
];

function sanitizeCapture(raw: string): SanitizedEvidence {
let sanitized = raw;
for (const pattern of SENSITIVE_PATTERNS) {
sanitized = sanitized.replace(pattern, '[REDACTED]');
}
return {
content: sanitized,
redactionCount: countRedactions(raw, sanitized),
timestamp: Date.now()
};
}
