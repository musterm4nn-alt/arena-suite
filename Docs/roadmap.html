What's left to build

The planned milestones in the order I'll do them, then the ones waiting on a decision or on you. Claude updates this page each time one is finished.

Planned, in order 4

  1. 1

    Agent detail next

    Archive the full content of agent-mode conversations, which today only show their history entry. It starts with a live look at Arena's detail route in the proof tool (announced before it runs); the app is changed only once that route is confirmed.

  2. 2

    Bulk export of the filtered history

    Export every conversation the sidebar's filters and search currently show in one go, in the formats single conversations already have (Markdown, normalized, raw, JSONL).

  3. 3

    A clearer Maintenance page

    Group Verify, backups, datasets and diagnostics by what they're for, put the everyday actions first, and make each result say plainly what to do next.

  4. 4

    Maintenance tools (plan §14)

    Remove chosen conversations from the archive with a checked journal rewrite, try a newer decoder on the archive and keep or roll back the result, and quick or full Verify.

Offered, waiting for your go 5

  • Fetch all old attachments at once decision

    The files already in your archive have expired links. Today each conversation's files come with its next Refresh; this would refresh them all in one paced run.

  • Safer journal recovery decision

    When damage sits in the middle of the last journal file, refuse and explain instead of setting aside the complete records after it.

  • Automatic test runs (CI) decision

    Run the test suites on every push. Needs a macOS build machine with this Xcode.

  • Tests for the remaining edge cases decision

    Accounts changing in the middle of a backup, cancelling a backup mid-copy, and the archive list refreshing after an index rebuild.

  • Backup to GitHub decision

    Kept separate because it sends private conversations off this Mac.
