# Phase 5 — native UI

Plan v3 §11 and §13 (Phase 5). 2026-09-24. Typeface: Departure Mono 1.500 (Helena Zhang, SIL OFL 1.1;
bundled with its license in `App/Resources/Fonts`), registered at launch, used at 11 pt and 22 pt
(the font's pixel grid). Falls back to the system monospaced font if the file is missing.

## Definition of done

| Criterion | Result |
|---|---|
| All synced conversations browsable offline | The main window reads only the local index: 57 conversations across 3 accounts, filterable per account. Transcripts render turn by turn with battle lanes side by side (never merged), model names from revealed claims, collapsible reasoning and tool blocks, inline Markdown, attachments, and your recorded votes. List-only (`agentic`) and "not on Arena" entries are labeled. Snapshot picker when a conversation has several. |
| Searchable offline | FTS over the latest snapshots, all accounts or one; reasoning and tool text opt-in; results jump to and highlight the message. |
| Raw evidence reachable from any displayed message | Every message has an evidence button: the inspector lists each block's JSON path in the source body and reads the exact journal record (sequence, segment, offset, length, SHA-256 verified on read, envelope). The raw body is shown only on request, with a warning that it contains Arena's per-message telemetry; text or hex. |

Also: sidebar with account states, Sync History / Stop, last manifest, decoder warnings and unknown
fields surfaced ("Attention"); accounts sheet from Phase 2; index updates after each sync and at launch.
Screenshots were taken of the app window only (`Tools/Dev/window_shot.swift`).

Development-only launch flags, compiled into Debug builds only (verified absent from Release):
`--preview-conversation "<title prefix>"`, `--preview-search "<text>"`, `--sync-on-launch`, `--archive-root <path>`.

Transcript layout rules (`ApplicationActions/TranscriptLayout.swift`, tested): turns start at `user`
messages; only `assistant` messages go into lanes; an unexposed lane is its own labeled column; other or
missing roles are listed separately; regenerations are flagged; votes attach only to the turn holding all
their messages. Review: `Docs/reviews/2026-09-24-phase5.md`.

Not in Phase 5: exports (Phase 6), keyboard shortcuts beyond system defaults (Cmd-F focuses search via
`.searchable`), VoiceOver pass beyond labels on custom controls.
